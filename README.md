# Sushanth Bandari — Portfolio

> Full-Stack Developer & AI Builder based in Hyderabad, India.

A production-grade, interactive portfolio website showcasing 7+ real-world engineering solutions, hackathon-winning projects, and AI integrations.

---

## ⚡ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router & Turbopack)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **UI & Animation**: [React 19](https://react.dev/), [Tailwind CSS v4](https://tailwindcss.com/), [Framer Motion](https://www.framer.com/motion/)
- **Design System**: Space Grotesk + Inter, technical circuit board canvas, custom dual-layer cursor, and high-contrast amber/navy palette (`#000000`, `#14213D`, `#FCA311`, `#E5E5E5`, `#FFFFFF`).

---

## ✨ Features

- **Interactive Hero**: Dynamic typewriter role rotator, floating portrait, quick stats, and social links.
- **Dynamic Circuit Canvas**: Interactive canvas background with glowing nodes, electrical pulses, and mouse tracking.
- **Project Case Studies**: Dedicated slug pages (`/work/[slug]`) detailing problem statements, architectures, and tech stacks.
- **Interactive Slideshows**: Multi-photo carousels with ambient blur borders in About and Achievements sections.
- **Portfolio Assistant**: Keyword-driven local chatbot widget providing instant answers about projects and experience.
- **Printable Resume**: Dedicated, clean resume view (`/resume`) with instant print/download styling.
- **Contact Form**: Interactive message composer with client pre-fill fallback and copy-to-clipboard actions.

---

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sushanth005/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```
